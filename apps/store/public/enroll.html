Enroll a card

Add an open-loop prepaid card to the funding pool, so an agent can spend from it later without you being present.

The card number never reaches this server. It is collected in a frame served by Stripe and posted straight to them. What comes back here is a PaymentMethod id — pm_… — and that is all this project ever stores. Storing the number itself, even encrypted, would put the whole codebase in scope for PCI SAQ-D.
